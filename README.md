# Kingdom Clash 2D

An original touch-friendly 2D kingdom strategy prototype made with Godot 4.

## Gameplay
- Gather gold, wood and food
- Recruit five soldiers at a time
- Upgrade your castle and barracks
- Attack an enemy camp, earn loot, and face stronger enemies
- Automatically save progress locally
- Landscape layout for Android

## Build APK
The GitHub Actions workflow **Build Kingdom Clash 2D Android APK** runs on pushes to main/master and can be started manually from Actions. When it succeeds, download the `KingdomClash2D-Android-APK` artifact from the workflow run.

This is a prototype source build. It must pass the remote Android export workflow before an installable APK is available.
