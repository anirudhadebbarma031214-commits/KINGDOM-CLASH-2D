# Kingdom Clash — 2D Strategy

An original browser-based medieval kingdom strategy prototype inspired by the broad genre of castle-building strategy games.

## Play
Open [index.html](./index.html) in a modern browser, or enable GitHub Pages: **Settings → Pages → Deploy from a branch → main → /(root)**.

## Features
- Canvas-drawn kingdom map and clickable building plots
- Castle upgrades and resource gathering
- Farms, lumber camps, quarries and barracks with passive production
- Footman and archer training
- Playable strength-based battles against an evolving bandit outpost
- Local save/restore using browser storage
- Room-code lobby interface prototype
- Responsive desktop and mobile layout

## Multiplayer status
The room-code interface is currently a lobby prototype, not real cross-device networking. Real online multiplayer needs a shared backend (for example Supabase Realtime) plus secure server-side validation for game actions. No credentials are embedded in this static site.

## Web only
This project is web-only. No Android APK build is included.
